# Contributing

Contributions are welcome.

## Before you start

For a substantial change, open an issue or discussion using the project's
available collaboration tools before starting work.

Use the repository's README and development documentation for setup,
build, and test instructions. Follow the existing code style and include
tests and documentation updates where appropriate.

## Submitting a change

1. Make a focused change.
2. Run the relevant checks documented by the project.
3. Explain the purpose of the change and any compatibility considerations.
4. Submit a pull request or use the contribution mechanism provided by
   the repository host.

Do not submit secrets, confidential information, or material that you
do not have permission to contribute.
